# File Index

- `PROJECT_BRIEF.md`: project idea, user problem, outputs and core workflow.
- `project_structure.md`: course requirements, WBS, risks and acceptance criteria.
- `AGENTS.md`: coding and generation rules.
- `rag_decision.md`: rationale for the mandatory RAG architecture.
- `README.md`: project setup outline.
- `.env.example`: environment variable placeholders.
- `knowledge_base/primary/`: fictional internal AI governance documents with intentional documentation gaps.
- `knowledge_base/secondary/`: the official EU AI Act PDF, optional public uploads and supporting reference notes.
- `docs/prompt_templates.md`: dynamic prompts for governance document generation, internal updates and optional LinkedIn posts.
- `docs/data_model.md`: shared records for documents, chunks, retrieval and generated drafts.
- `docs/test_plan.md`: functional and safety tests.
- `docs/uniqueness_comparison.md`: template for comparing against a generic LLM.
- `docs/demo_script.md`: short presentation flow.
- `outputs/`: generated Markdown drafts.

The Python files under `src/` are part of the agreed architecture and still need to be implemented. Supporting secondary notes are not authoritative legal text; the official EU AI Act PDF is the baseline regulatory source for the MVP.
