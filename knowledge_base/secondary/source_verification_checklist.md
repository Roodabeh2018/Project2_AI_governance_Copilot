# Source Verification Checklist

For every public regulatory or framework source:
- Prefer the official issuing organisation's publication.
- Record title, issuer, identifier/version, publication date and URL.
- Record retrieval date.
- Preserve article/section headings and page numbers during PDF/text conversion.
- Verify exact citations before using them in generated content.
- Do not present a summary note as the full legal or standard text.
- If a source cannot be verified, say “insufficient source” for claims that depend on it.
