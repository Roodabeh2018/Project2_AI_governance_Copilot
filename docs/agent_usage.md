# How `AGENTS.md` guided the work — verifiable examples

`AGENTS.md` holds the rules for the generation agent (grounding, citations, placeholders, no verdicts, public-content rules) and for the coding agents and people working on the repository (read the shared contract first, focused changes, run tests, never commit secrets, do not claim success without verification). The examples below come from Color C's work. Each one names the Trello card, the Must ID, the `AGENTS.md` rule, what changed, the test that checks it, and the commit or PR. Every SHA and test name can be checked with `git show <sha>` and `python -m pytest -q -k <test name>`.

## Process rule in practice

`AGENTS.md` asks contributors to “report files changed, commands/tests run, outcomes and limitations”. Every Color C pull request since #10 states the full test result (for example *“143 passed (LLM_PROVIDER=mock)”*) and the open limitations. Each reviewer finding was answered with a regression test before re-review (PRs #10, #13, #14, #15, #16).
